## 2025-05-14 - [CLI List Readability]
**Learning:** For interactive CLI tools, raw lists are hard to scan. Using aligned tables with headers significantly improves the user's ability to quickly identify and select options. Adding subtle visual feedback like success banners and color-coded links makes the final experience feel more polished and "complete".
**Action:** Always format lists in CLI tools as aligned tables. Use ANSI colors for critical success/failure information to guide the user's attention.
